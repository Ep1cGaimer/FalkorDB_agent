# Independent seeded Git history oracle — 2026-10-18

The 100-seed synthetic batch passed **10,800/10,800 deterministic state and invariant checks**, with zero recorded errors or failures. A separate replay of the recorded results verified **5,400/5,400 citations** against generator-maintained source bytes and selected revisions. **This is partial T3 evidence; T3 is not validated.**

The independently assigned reviewer wrote [the generator/harness](../../artifacts/goal-history-oracle/run_oracle.py) after reading T3 and public production APIs/tests. Expected values come from generator-owned complete file dictionaries, operation labels, parent lists, and deterministic seed values, rather than graph output. Every seed's expected state was written before its first production import; [the consolidated expected-state manifest](../../artifacts/goal-history-oracle/expected-state-manifest.json) was extracted from those retained expectations afterward. This is independent authorship, not a claim that the reviewer was blind to implementation. No sealed tasks, held-out questions/oracles, Click source, or model outputs were used.

Seeds **0–99** vary symbol names, values and fix strings in one deliberately narrow DAG family: initial → fix → exact content revert → revert-of-revert → overwrite → deletion → same-path recreation, plus a divergent unrelated branch from the initial commit. A second independent repository reuses the path and symbol. These are 100 generated histories, not 100 different structural adversaries.

Each history checked exact indexed path/content SHA-256 pairs against expected full trees; symbol presence before and after all changes; exact `fix_status` (`PRESENT` or `ABSENT`); ordered direct parents and two ancestry traps; reverse revision indexing order; unchanged pinned answers after adding the unrelated branch and repository; and moving a tag from the fix to the deletion. `git ls-tree`, `git show`, `git cat-file -p` and tree resolution independently checked expected tracked bytes, parents and tree identities. Earlier symbol/file evidence was queried again after deletion and subsequent imports. All production API selections use full commit hashes except the explicit tag checks.

The production run made **500 imports** and recorded **3,100 fix-status/symbol-history query pairs**: **800 PRESENT**, **2,300 ABSENT**, with no false current-presence conclusion in the tested reversion, overwrite or deletion cases. It retained **115,500 real FalkorDB trace records**, including Cypher, parameters, returned rows, query identifiers and timings. These counts include repeated pinned-revision observations across invariant stages, not distinct independent questions.
